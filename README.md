# Kumagai K-400 — Central de Injeção Eletrônica Programável

Manual técnico, especificações de hardware e documentação oficial da central de injeção eletrônica desenvolvida para motores Ciclo Otto de alta performance.

---

## 📋 Visão Geral
O **Kumagai K-400** é uma ECU programável de arquitetura robusta, projetada para garantir alta imunidade eletromagnética, precisão no controle de injeção e ignição, e confiabilidade em condições extremas (*Motorsports*).

---

## ⚙️ Especificações Técnicas
* **Microcontrolador:** Arquitetura de 32-bits de alta performance.
* **Alimentação:** Sistema protegido contra surtos e inversão de polaridade (12V Automotive).
* **Entradas de Sensores:** 
  * Leitura de rotação e fase (CKP / CMP).
  * Sensores de pressão (MAP), temperatura (TPS, IAT, CLT) e sonda lambda.
* **Saídas de Acionamento:** 
  * Drivers dedicados para injetores e bobinas de ignição.
  * Saídas auxiliares configuráveis para relés, eletroventiladores e comandos variáveis.
* **Comunicação:** Interface USB / Serial para calibração em tempo real via software de sintonia.

## 🛠️ Instalação e Configuração
1. **Alimentação e Aterramento:** Utilize cabos blindados e siga rigorosamente o esquema de malha de terra para evitar ruídos parasitas no sinal dos sensores.
2. **Calibração Inicial:** Conecte a interface de comunicação e valide a leitura dos sensores base (TPS e MAP) antes da primeira partida.
